# BMS Protocol Simulation

This Python script simulates a Building Management System (BMS) integrating HVAC and Lighting systems using BACnet, Modbus, and KNX protocols. It demonstrates how different protocols can interact with building components to control temperature, fan speed, and lighting.

## Language

`python`

## How to Run

Run the script using: python bms_simulation.py
